# 🍽️ Zomato Dataset Analysis & Visualization

## 📖 Introduction
This project explores and visualizes the Zomato restaurant dataset to uncover meaningful patterns and trends in the food industry.  
It focuses on **restaurant ratings, popular cuisines, cost patterns, and location-based preferences**, with visual insights created using Python data analysis libraries.

---

## 🎯 Goals
- Clean and prepare the raw dataset for analysis.
- Explore **customer preferences** based on cuisine and location.
- Identify trends in **average cost and ratings**.
- Visualize findings for better decision-making.

---

## 📂 Dataset Information
The dataset includes:
- Restaurant details (Name, Location, Cuisines)
- Service availability (Online delivery, Table booking)
- Ratings and votes
- Average cost for two people

---

## 🛠️ Tech Stack
- **Python** – Primary programming language
- **Pandas** – Data cleaning & manipulation
- **NumPy** – Numerical processing
- **Matplotlib** & **Seaborn** – Data visualization
- **Jupyter Notebook** – Development environment

---

## 📊 Insights from the Analysis
- Most popular cuisines among Zomato users.
- Cities with the highest number of listed restaurants.
- Relationship between **price range and ratings**.
- Trends in **online delivery & table booking adoption**.
